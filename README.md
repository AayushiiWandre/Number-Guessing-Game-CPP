# 🎯 Number Guessing Game in C++

## About the Project
This is my first C++ project! It is a simple number guessing game where the computer generates a random number between 1 and 100, and the player tries to guess it.

## 🛠️ Technologies Used
- C++
- Random number generation
- Conditional statements
- Do-while loop
- User input and output

## 🎮 How to Play
1. Run the program.
2. Enter a number between 1 and 100.
3. Follow the hints to guess the secret number.
4. Enter 0 to exit the game.

- Generating random numbers
- Using if-else statements
- Working with loops
- Taking input from the user
